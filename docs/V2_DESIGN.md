# V2 deterministic multi-signal design

Clean implementation commit `5d1647386fe935412a68b333514858f6b2039d0f` passed the [final engineering audit](V2_FINAL_AUDIT.md) without threshold retuning. V0 and V1 bytes remain independently reproducible. This is a public-data research engine, not an execution system or a calibrated forecast.

## Input and ownership

The core uses only the accepted Kraken BTC/USD depth-100 book and recorded one-second `ClockTick`s. After the shared V0 processor applies each committed tick, a single owner passes its `book.View` and detached `book.Quote` to a V2 engine. V2 calls an unchanged, private V1 engine first, using the same run ID and `v1.DefaultConfig()`, and consumes that engine's causal minute feature snapshot. No outcome, manifest, replay iterator, wall clock, or future-complete table enters the decision path. One V2 intent is emitted at the first tick of each UTC minute, including unhealthy and warm-up minutes. Equal-time ticks do not add feature or book-pressure samples. A gap over two seconds, a stale quote, or a new book generation resets all V2 rolling state. As-of time is the recorded tick's `UsableFromTime`; ordinal breaks ties. The current quote must have the V0 generation and last-book ordinal, a last-book ordinal no greater than the tick ordinal, exact BBO identity with the V0 view, and a book age no greater than two seconds.

The V1 engine, policy, journal schema, evaluator and frozen result are not modified by V2. V2 has its own versioned config, `SignalResult`, `Evidence`, `OpportunityAssessment`, intent, journal and research report. Both live and replay call exactly the same V2 `ApplyTick` method. Live decision-ready/durable time and watchdog veto are separate operational acknowledgments, never replayed as canonical market facts.

## Fixed features, families and horizons

All numeric directional scores are signed **micro-bps**, where 1 bp = 1,000,000 micro-bps. They are descriptive observed magnitudes, not expected return or calibrated probability. V1's `return_60_bps`, `displacement_300_bps`, spread and RMS are retained at their frozen definitions. V2 adds only a book-pressure sample: top-five bid and ask **base-size** totals from a fresh current-generation quote, `(bid_size-ask_size)/(bid_size+ask_size)`, rounded to integer millionths. One sample is admitted per distinct last-book ordinal at a tick. The rolling pressure is the equal-weight mean of distinct samples in `(T-30s,T]`; it is available only with at least ten observations spanning at least 20 seconds, and is bounded to the latest 32 samples. An over-two-second tick gap or quote-quality failure resets it. It is a visible-depth proxy, not aggressor trade flow; no signed trades are inferred.

`SignalResult` carries immutable family/version, status (`ACTIVE`, `NEUTRAL`, `UNAVAILABLE`, `INVALID`), direction (`LONG`, `SHORT`, `FLAT`), observed magnitude in micro-bps or imbalance millionths with its units, intended horizon, reason, and contributing as-of ordinal/generation. `NEUTRAL` is a valid current observation below a fixed trigger; `UNAVAILABLE` has a missing dependency; `INVALID` is malformed or nonfinite input and fails closed. No generic confidence or probability field exists. Later derivatives, cross-market, signed trades, and breakout families are postponed. They require their own source and global arrival-order design, historical tape, and predeclared incremental hypothesis; their absence cannot break core V2.

## Aggregation, disagreement and opportunity

The two price families form **one price slot**: if both are active and oppose, the slot is `CONFLICT`; if exactly one is active, it votes its direction; if both agree, it still contributes one vote. `book_pressure` forms one independent mechanism slot. Thus two correlated price features cannot outvote the book. Directional consensus is available only when both slots have an active, agreeing vote. If both slots are active and oppose, `disagreement=1`; if they agree, `disagreement=0`. A price-family internal conflict also sets disagreement to 1 and vetoes. If either slot lacks an active vote, disagreement is `UNDEFINED`, not zero. The aggregate exposes both slot votes, active/unavailable family counts, disagreement, and explicit suppression reasons. Fixed slot weights are one each; there is no fit or hidden normalization.

The opportunity assessment separates directional consensus from feasibility. It records reference USD 100, current-book side-specific round-trip friction from the accepted V1 cost function, quote age/generation, spread, two active mechanism slots, and a **historical-move magnitude proxy**: current absolute V1 60-second return for trend, or absolute 300-second displacement for reversion. If both price families agree, take the larger absolute observed magnitude; this rule is fixed before V2 outcomes. This proxy is an observed screening heuristic, **not** `E[R_gross]`. A candidate passes the frozen exploratory screen only if the proxy is strictly greater than current friction plus 10 bp. The same 20-bp taker fee and 5-bp adverse allowance per side, depth sweep, and 300-second horizon as V1 apply. Do not count spread a second time. Missing depth or quote quality makes the assessment unavailable. No directional intent implies an actual fill. Default spot configuration cannot issue `SHORT` without a versioned hypothetical short mechanism and borrow/carry assumption; the short signal remains visible but action becomes `NO_TRADE`.

Decision reason priority is: invalid/unhealthy quote or generation; V1/V2 warm-up and missing required family; price-family conflict or opposite slot votes; no supported direction; unavailable cost/depth; proxy at or below friction plus margin; unsupported short feasibility; otherwise `MULTI_SIGNAL_CONSENSUS`. Regime `WIDE` suppresses all three families; `VOLATILE` remains visible, never silently changes a weight. A neutral family is not recoded as unavailable. The V2 intent carries the frozen V1 feature snapshot, three ordered signal results, two slot votes, disagreement, opportunity, action/reasons, config digest, tick/quote provenance, expiry and horizon. It never contains size, order type, fill, leverage, account data, or calibrated probability.

The frozen eligibility mask is health/current quote/valid depth at decision time, independent of V2 action. Report calendar minutes, eligibility, paired episodes and all censored reasons before net returns. Use the same paired endpoints for V2 policy, V1 policy, simple momentum, simple reversion, always-long, no-trade, and action-frequency-matched deterministic random direction. Report exploratory 30-minute UTC block uncertainty and four chronological six-hour development folds, but no significance claim from one day.

One decision per minute is an **observation**, not an independent trade. A research-only deduplication view keeps the first directional action of a thesis and suppresses later same-direction actions until its 300-second outcome horizon; reversal starts a new thesis only after the prior horizon closes. `NO_TRADE` never closes a hypothetical thesis early. Report both raw intent frequency and deduplicated thesis count; do not feed thesis state into the live decision engine. Cohorts include each family active alone, price/book agreement and disagreement, neutral/unavailable distinction, regime and opportunity rejection reasons, and fixed proxy/friction buckets. Family correlation and ablation are descriptive; remove independence language if conditional evidence fails. No thresholds or weights are chosen from V2 outcomes.

The book-pressure family also receives a **separate 30-second research endpoint** on the same predeclared healthy/depth-eligible decision population. It uses the first fresh post-two-second entry, first fresh post-entry-plus-30-second exit, the same path censoring and V1 side-specific cost function, including the disclosed hypothetical short-borrow scenario. Report pressure action, always-long, matched-random, V1 policy, V2 policy, and no-trade controls on its own paired 30-second population. The five-minute family/cohort comparison tests book pressure only as a *confirmation* of a price thesis; it must not be labeled standalone 30-second skill. Neither horizon counts overlapping minute episodes as independent trades.

## Reproducibility, performance and gate

Config and schemas are canonical JSON with SHA-256. Fixed family order, integer-rounded features, stable summation order and ordinal tie-breaks define canonical output. The raw run ID, source manifest digest, source revision, V1 benchmark digest, V2 revision, Go version, config digest, intent digest and report digest must be recorded. Two complete independent full replays must recover accepted V0 normalized/state hashes and identical V2 intent/report bytes. A short public live run must produce a current healthy minute after both V1 and pressure warm-up, durable V2 intents, bounded operational lag, and exact raw-replay intent parity. Unknown or unavailable optional feeds cannot alter core bytes.

Live only, an optional timing sink records fixed-stage durations for V1 baseline update, book-pressure sampling, trend, reversion, aggregation and opportunity cost. It returns no clock value to the engine; timings are excluded from canonical intents and replay. Journal counters for family status, action, disagreement and reasons use only fixed IDs and reason codes. An instrumentation parity fixture requires byte-identical intents with and without the timing sink.

Tests cover temporal boundaries, equal stamps, future-poison, late event times, generation reset, stale quote, unavailable versus neutral, all three families, internal and cross-slot conflict, side-correct costs, short feasibility, reason precedence, serial ownership, research censoring and deduplication. Run `go test -count=1 ./...`, WSL `CGO_ENABLED=1 go test -race -count=1 ./...`, `go vet ./...`, `gofmt -l cmd internal`, `git diff --check`, and a bounded engine benchmark. Acceptance requires the deterministic full replays, honest comparative/cohort report, live/replay smoke parity, and final adversarial audit. Negative or zero-action economic results do not fail the engineering gate. One exposed day cannot establish alpha or calibrated expected edge.
